The sticky top bar, styled like tmux: the handle on the left, sections as numbered tabs, the theme toggle and the mobile menu on the right.

**When to use.** Once, at the top of the page. Tabs come from the section registry; below `md` they collapse into `MobileMenu`.

**The consumer provides.** Nothing: it reads the profile and the registry.
