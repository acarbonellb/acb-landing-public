A vim-style `:colorscheme` button that switches between Tokyo Night and Tokyo Light.

**When to use.** In the header only. It sets `data-theme` on `<html>` and remembers the choice; the label is chosen by CSS, so it never disagrees with the page.

**The consumer provides.** Nothing.

Source: `src/components/theme-toggle.tsx`. Compiled from the repository, not hand-written.
