The ask-my-agent section: the live chat window, privacy note and MCP connection.

**When to use.** In the page. Here it renders as on the site, but the artifact cannot reach the agent, so a sent question fails. `endpoints: null` shows the coming-soon note instead.

**The consumer provides.** Optional `endpoints`; defaults to the demo ones (`data.endpoints`).

Source: `src/components/sections/agent.tsx`. Compiled from the repository, not hand-written.
